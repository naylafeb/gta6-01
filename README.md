An original open-world crime game for the [Make GTA 6](https://make.fun/bounty/gta6-01) bounty on make.fun: a sun-soaked coastal city, a five-star wanted level, and a dramatic police chase with cars, a helicopter and a tank.

Play it: serve `game/` with any static HTTP server and open `game/index.html` in desktop Chrome.
